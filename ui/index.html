Multiverse Mages

Interface prototypes

Eleven static screens, each built to answer one question that could only be settled by operating something rather than arguing about it.

They all read one recorded universe through shared/session.js, and each says at the top which run it is reading — or which capability the read path does not carry, and why. Nothing here ships. None of it is imported by a package or covered by a test glob. Several of these contradicted the design that specified them, which is the whole reason they exist — the findings are collected in docs/design/interface-findings.md.

The god's verbs

The rulesetruleset/

Does the grid read as nineteen switches with combinatorial consequences, or as seventy independent toggles?

 The ruleset as a symmetryruleset-symmetry/

How unequal are those nineteen actually? Forbidding Intellego costs 102 nodes where the others cost about sixty.

 Eight exceptionsedicts/

The edict budget is a slot, not a price. What does spending one of eight feel like?

 Choosing whotargets/

Six actions carry an entity handle. How does a person pick one mage out of thousands?

 Commitmentscommitments/

Which acts cannot be taken back, and does the interface make that legible before the click rather than after?

The world

The mage, up closemage/

Can a player be told why an autonomous mage chose what she chose, from state the core already has?

 Where the knowledge isknowledge/

Four vessels, four ways to lose it. At the measured redundancy, how often is anything on its last copy?

 Tempotempo/

What pacing does a world tick get, and which events may interrupt it? Speed decides what an event is.

 Ascensionascension/

A run ends gloriously or it stagnates. Can a player see which one they are heading for?

Raids, and light

Playing a raidraid/

Muster, contact, resolution — agency spends down as the fight goes on. Forbid a cell mid-raid and it locks until the end. You can rewind to look, never to act.

 The god's lightglow/

Cyan is the god's own light; the form hues stay the world's. Does that survive a vellum ground?

All of it at once

The consoleconsole/

Not a twelfth direction — the composition. Every surface the read path can feed, from one frame of one recorded universe, against one clock. The gaps line up next to the things that work.
Served by npm run ui from the repository root. Each prototype states its own known costs in its header comment — ruleset/ reimplements permits() rather than importing it, which is the first thing to fix if any of this becomes the client.
