One universe, one clock

The eleven prototypes each answer one question about one surface. This asks whether they compose — every pane the read path can feed, drawn from a single frame of a single universe, against a single clock.

Under npm run play this universe is running. Advance the clock, choose a verb, choose its parameter, and cast: the action goes to agent-api's admission gate and the world on this page is the world after it. Opened over a plain static server instead, the same page reads a finished recording and the cast controls are gone — the strip above says which.

Scrub the spine. It is the whole run at once, and it is here because the read path emits states and no events: the only way to see that a species ended is to plot the run and look at it.
