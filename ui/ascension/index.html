The ending you have to choose

Action 15 is unlike the other fifteen. Ascension is declared, never automatic — satisfying a path unmasks the action and does not end the run, and a universe that declines keeps simulating normally. The condition can also lapse: lose the qualifying mage and the mask goes back to false. It is a button that appears, that you may refuse, and that can be taken away while you hesitate. Nothing else in the action space behaves like that.

And the two paths pull opposite ways on whether to wait. Apotheosis is a summit you can lose by waiting; Enduring Canon is a record you can break by continuing. Step the timeline — the interesting part is the moment it lapses.

What operating these settles

A lapse is the whole design problem, and only one direction survives it. In direction A the button simply vanishes, and a player who was deciding is given no account of what happened — the most consequential control in the game silently stops existing. B and C can both say which condition broke, which is the difference between a bug and a story. The spec already reports the gap between first-met and declared as a metric, so the simulation considers hesitation interesting; the interface should be able to explain what it cost.

Showing the paths all run changes what kind of game this is. Direction B makes ascension a thing you steer toward for hours, which is what a win condition usually is. But vision §8a wants a summit that is reachable but not routine, and a permanently visible progress bar is an invitation to optimise. There is a real argument for A's austerity: an ending that arrives unannounced is a better ending, and the balance harness measures whether it arrives at all.

C is the only one that prices the decision. Prestige is earned at run end from bounded achievement, grants stocks and never rates, and its head start decays within the next run. So declaring is a trade — a finished thing now against an unfinished thing continued — and a player cannot make that trade without seeing both sides. Showing what you would carry and what you would abandon at the moment of choosing is the only version where refusing is a real option rather than a mistake.

What none of these can show yet. The meta-game the author specified this session — clearing a bubble by conquest, rejoining with prestige — collides with ascension as a second win condition, and is explicitly not decided for v1. Every direction here assumes ascension is the ending. If conquest becomes a second one, this screen has to present two endings that compete, and none of these three extends to that cleanly.
