Where the knowledge is

Knowledge is physical. It occupies minds, memory palaces, grimoires and libraries, and the state model is specific about each: exactly one instance exists per written copy, shelving a book rewrites its location rather than making a new one, mind and palace instances decay while written ones never do, and a palace dies with its holder and cannot be looted or burned. An interface that blurs those four into "you know it" throws away the pillar.

Node existence is derived — count(instances) > 0, never a stored flag — and libraryDependence is the set of nodes surviving on exactly one instance. Move the redundancy slider: that number is what decides whether any of this matters.

What operating these settles

Drag the slider to 55 and all three directions become the same screen — and that is now measured rather than predicted. W8 landed raids: books burn, grimoires fell 1232 to 354 in a raid season, and nothing was lost — nodesLost is 0.00 for six of eight strategies and libraryDependence sits at 0, because at 50–80 copies per node a whole library is held fifty other places. The campaign's own verdict: concentration, not the absence of a mechanism, is the remaining problem. So the risk direction has nothing to sort, permanently, until copies stop being free — and no decay constant and no interface can change that.

Vessels are not decoration and only direction B makes them primary. The four location kinds have genuinely different failure modes — a mind dies, a palace dies unburnable, a book burns or is stolen, a library takes everything shelved in it at once. A player deciding whether to fund a scriptorium or bless an archivist is choosing between those failure modes, and a by-node list flattens the choice into a count.

The one thing a by-node list has that the others do not. It is the only direction where a node that does not exist yet can appear at all — an empty row is a node this universe has never held, and that is the thing a god deciding where to grant founding knowledge needs to see. Directions B and C can only show what exists, because they are organised by where instances are.

Rediscovery deserves a state and has none here. A node that once existed and was lost is not the same as one never known: re-deriving it costs at least three times research, and the distinction is a persisted per-node ever-known record. None of these three directions distinguishes "never had it" from "had it and lost it", and the second is the more interesting row in the game.

Prototype · not the client. Instance placement is generated from a seeded PRNG over the real 51-node v1 subset; node names, cells and tiers are real. The redundancy distribution is deliberately not the measured 50–80 copies per node — see above.
