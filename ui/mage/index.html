Until the last copy stops being teachable

Keep the Name Close exists in one place, and that place is her memory. It is never destroyed — her floor is 128, so it settles there and stays. It stops being transmissible, which is worse, because nothing announces it. Below 512 she cannot teach it and cannot pass it on, and nothing in the subsystem restores mastery — practice does, and practice is an operation somebody has to perform.

704 − 512 = 192  ·  decay 16/tick at retention 512  ·  192 ÷ 16 = 12 ticks  ·  1 tick = 1 month
The panel cannot compute any of this. Mastery is a snapshot field, but the floor, the per-tick rate and the threshold crossing are rules computations, and contracts §5 forbids the renderer performing them. So either the core publishes them the way libraryDepth already is, or this reading cannot exist and 704 stays inert.

Reading the staff. Height is how firmly she holds a thing; the stem is what she has already forgotten. The strip beneath counts copies elsewhere in the universe — so the column with a gap in it is the one that can be lost. Sound-design §0.3 requires salience parity: whatever the audio makes urgent, something visual must make equally urgent. Loss is not an alert here. It is a gap where depth should be, and a dotted line showing where the survivor is going.

Without this, autonomy reads as lag: a player watches a better option go untaken and concludes the simulation is broken. ReevaluationReason is already an exported union — no-incumbent | complete | infeasible | scheduled | held — which is nearly display copy as written.

A masked goal says which, never why. FeasibilityOutcome carries feasible, masked and maskedCount — enough to grey a row out, not enough to say anything about it. The panel can report that seek-teaching is unavailable, but not that it is unavailable because no living mage holds a node she can still learn — which is the fact that would send a player to found a university. The interface's own comment calls the masked list "for attributing a stall"; attributing a stall to a player needs the reason, and the reason is computed inside isFeasible and discarded.

Two things this block wants and cannot have. effort-progress holds subject, kind, nodeId, counterparty, progress — and no tick, so "she set this down twenty-three years ago" is not derivable.
